# Provenance hashes

These files are SHA-256 integrity fingerprints of the repository tree as recorded in each file (generated before commit `e1f578d`)
(the files were renamed afterwards; the recorded hashes refer to the original paths). They let anyone
check that a file is byte-identical to the archived version. They are **not** a certificate of
mathematical correctness, peer review, or acceptance by any body. Correctness evidence is the Lean
build plus the axiom report in `AXIOMS.md`, reproduced by CI.

DOI note: `PROVENANCE_HASHES.json` records `10.5281/zenodo.23653013`, the version DOI of the v1.0.0 snapshot (commit `00fee0f`).
The repository-wide concept DOI, which resolves to the latest version, is `10.5281/zenodo.23653012`.
